# Print history

Assistants may record useful print outcomes Kyle supplies in NOTES.md. Detailed `YYYY-MM-DD_<build>_<revision>_<attempt>.md` records using [TEMPLATE.md](TEMPLATE.md) are optional, including for failures or calibration prints. Link the exact build revision, source and `.3mf`; retain the settings used for that attempt even if later revisions change.

No FTC print attempts recorded yet. A successful slice is not evidence of a successful physical print.
