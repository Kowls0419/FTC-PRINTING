# Builds and design iterations

Create one folder per mechanism, assembly or part. Copy [TEMPLATE.md](TEMPLATE.md) into that folder as its README. Store CAD/STEP/STL sources, revision-specific print files and test evidence alongside the record, or link to their exact locations.

First build: [Bot side panels — cut v1](bot-side-panels/). Use stable revision IDs and link print attempts to the exact revision. Record unsuccessful alternatives and failed tests as part of the design history.
